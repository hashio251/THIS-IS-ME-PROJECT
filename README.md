# アートシンキング作品紹介サイト

## 概要
このサイトは、アートシンキングの授業を通して制作したものになります。「THIS IS ME」をテーマとした作品を個人で制作するというプロジェクト内容。
プロジェクト目的に沿って、「自己とは何か？」ということを念頭に創作した作品になります。
自己とは何か？と考えた際に、「自己＝今に至るまでの断片」という結論に至ったので、「今まで自分を形成してきたものは何か？」というところから考えました。
その結果、今は使わなくなったけど、過去によく使っていたもの、ハマっていたもの、そのような過程が現在の自分を作り出しているのだと認識し、作品の創作にあたりました。

私が所有している媒体である多種多様な媒体の素材を使用し、「日常の断片のコラージュ」を意識したミクストメディアの作品紹介ページです。
モネをイメージした背景と自己をアピールしたデザインになっており、作品の詳細や使用パーツを紹介しています。



## 作品について
### コンセプト
かつて日常であった断片（媒体）を集めて構成した混合メディアのコラージュ作品（ミクストメディア）です。
中学生時代にモネの作品に感銘を受けた記憶を元に、モネをイメージした青いキャンバスを背景にし、白いボウルから溢れ出す様々なオブジェクトと、黒い布地の上に配置されたミニチュアラーメンで、記憶と体験の断片を表現しています。
また、作品自体を人間（私）に見立て、表や裏、側面なども意識しながら作っています。表面は他者から見える私、裏面は心理的な自己を表現しています。

### 主要な要素
- **青いキャンバス**: モネの代表作である睡蓮風の背景（青をメインに、緑や黄色、赤なども使用）
- **白いボウル**: 様々な小物を収容する中心的な要素（ボウルはラーメンのどんぶりに見立て、この作品の中では顔として機能）
- **ミニチュアラーメン**: 実際に来ていた服の上に配置（この作品の中では服のボタンとして機能）
- **シルバーチェーン**: 要素間のつながりを表現
- **CD**:キャンバスの窪みを利用し、裏面に埋め込まれたCD（ここでは心の役割を果たしており、記録されたHDDとして機能）



## サイトの特徴
### デザイン
- **モネ風背景**: 複雑な色の混合によって自己の要素のバックグラウンドの多数さを表現した背景
- **レスポンシブデザイン**: スマートフォンやタブレットにも対応
- **スムースアニメーション**: スクロールやホバー時の円滑な動き

### 機能
- **ナビゲーション**: 固定ヘッダー
- **パーツ紹介**: 使用した各パーツの詳細・手順説明
- **ギャラリー**: 作品の様々な角度からの紹介

## 使用方法
1. `index.html` をブラウザで開く
2. ナビゲーションメニューから各セクションに移動
3. パーツカードやギャラリーアイテムにホバーしてインタラクションを体験
